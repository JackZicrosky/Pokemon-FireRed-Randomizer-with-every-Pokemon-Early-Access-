# Lucoa pack, round 3 (work in progress, not in the game yet)

Owner's feedback round: narrower hair, new cap and horns, 3/4 pose for the front pic; back pic rebuilt on
Red's FR/LG throw frames (his cap and face, so the cap sits on her head); front fishing frames and item
frames with Leaf-style movement. `owner_normal_v2.png` is the owner's latest walk/run sheet (used as is;
`owner_normal2.txt` is the same sheet in letters). Colour limits are ignored for now (extra colours).

Scripts take this folder as their argument, e.g. `python3 front7.py tools/rh/lucoa/v3`:
`front7.py` -> front.txt, `back3.py` -> back.txt, `fish_front.py` -> fishing frames 8-11,
`item_v3.py` -> item frames. `preview/` has the GIFs and stills sent to the owner.
